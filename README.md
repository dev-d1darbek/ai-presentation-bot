# 🤖 AI Presentation Telegram Bot (Python)

Жасанды интеллект арқылы кәсіби деңгейдегі презентацияларды автоматты түрде **.PPTX және .PDF** форматында дайындайтын **Telegram-ға арналған толыққанды Python жүйесі**.

---

## 🌟 Жаңа енгізілген мүмкіндіктер мен жақсартулар

1. **Жаңартылған таза UI/UX дизайн (Заманауи Apple / Keynote стилі)**:
   - Слайдтардағы артық қоршаулар, қалың сызықтар мен шектен тыс бұрышты «div-карточкалар» толық алынып тасталды.
   - Кең ауқымды ашық кеңістік (breathing room), талғампаз сол жақ акценттік индикаторлар, стильді пилл-бейджиктер және айқын типографика орнатылды.
   - Мұқаба (Cover), салыстыру, уақыт сызығы және статистика слайдтары кәсіби деңгейде қайта жасалды.

2. **PPTX және PDF қос экспорты (.PPTX / .PDF Export)**:
   - Презентация жасалған соң, бот бірден дайын `.pptx` файлын жібереді және оның астына **«📥 PDF нұсқасын жүктеу (.PDF)»** батырмасын шығарады.
   - Пайдаланушы бір батырманы басу арқылы телефоннан бірден ашылатын сапалы PDF нұсқасын алады.

3. **Толыққанды Әкімші статистикасы (`/admin`)**:
   - Жалпы тіркелген және бүгін кірген пайдаланушылар саны.
   - Барлық жасалған презентациялар мен бүгінгі көрсеткіштер.
   - Ең көп таңдалған дизайн стильдерінің ТОП-5 рейтингі.
   - Ең сұранысқа ие слайд сандарының статистикасы.
   - Соңғы сұраныстар мен пайдаланушылар тарихы.
   - **Жаппай хабарлама тарату (Broadcast / Рассылка)**: ботты қолданған барлық адамдарға бірден хабарлама жіберу мүмкіндігі.

4. **1-Tap Ergonomic Telegram UX & 30 Дизайн**:
   - Тақырыпты жазған сәтте бет санын 1 рет басу арқылы генерация басталады.
   - 30 дизайн бойынша 1 секундта лезде стильді ауыстыру (Instant Re-export).
   - DeepSeek, Google Gemini, OpenAI қолдауы + 100% автономды қазақша Fallback.

## 🚀 Іске қосу

1. Тәуелділіктерді орнату:
   ```bash
   pip install -r requirements.txt
   ```
2. `.env` файлын дайындау:
   ```bash
   cp .env.example .env
   ```
   `.env` ішіне `TELEGRAM_BOT_TOKEN` және өз Telegram ID-іңізді `ADMIN_IDS` жолына жазыңыз.
3. Ботты қосу:
   ```bash
   python bot.py
   ```
4. Тестілерді тексеру:
   ```bash
   python tests/test_system.py
   ```
