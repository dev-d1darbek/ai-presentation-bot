# 🤖 AI Presentation Telegram Bot (Python)

Жасанды интеллект арқылы кәсіби деңгейдегі презентацияларды (**.PPTX** және **.PDF**) және қорғау мәтінін (**.DOCX**) автоматты түрде дайындайтын **Telegram-ға арналған толыққанды Python жүйесі**.

---

## 🌟 Негізгі мүмкіндіктері

1. **Дайын құжаттан презентация жасау (PDF / DOCX / PPTX / TXT → Слайд)**:
   - Пайдаланушы ботқа реферат, курстық жұмыс, диплом немесе мақала файлын (`.docx`, `.pdf`, `.pptx`, `.txt`) жібереді.
   - Бот құжаттың ішіндегі мәтінді өзі оқып, бет санын таңдауды ұсынады да, құжат мазмұнынан дайын презентация құрастырып береді.

2. **Спикерге арналған қорғау мәтіні («🎤 Қорғау сөзі / Шпаргалка»)**:
   - Әр дайын презентацияның астында **«🎤 Қорғау сөзі (Шпаргалка)»** батырмасы бар.
   - Батырманы басқанда бот әр слайдты қорғағанда не айту керектігін (кіріспе сәлемдесу, негізгі слайдтар арасындағы көпірше сөздер мен қорытынды сөз) дайын **Word (.DOCX)** құжаты және чаттағы мәтін ретінде шығарып береді.

3. **Бұрын жасаған жобаларды сақтау («📂 Менің жобаларым»)**:
   - Пайдаланушының жасаған барлық презентациялары базада (`user_projects`) сақталады.
   - Төменгі мәзірдегі **«📂 Менің жобаларым»** батырмасы (немесе `/projects`) арқылы кез келген уақытта бұрынғы презентациясын қайта тартып алуға (`.PPTX`, `.PDF`, `🎤 Қорғау сөзі`) немесе басқа дизайнға 1 секундта ауыстыруға болады.

4. **Ақылды Глобалды Кэш жүйесі (Smart Cross-User Cache — уақыт пен AI токендерін үнемдеу)**:
   - Егер 1-пайдаланушы (`user1`) белгілі бір тақырыпқа және бет санына презентация жасаса, ол глобалды кэште (`presentation_cache`) сақталады.
   - Кейін (1 сағаттан соң немесе 1 күннен соң) 2-пайдаланушы (`user2`) дәл сол тақырып пен бет санына сұраныс жіберсе — **тіпті дизайны басқаша болса да** — бот AI-ға қайта сұраныс жіберіп уақыт жоғалтпайды: дайын құрылымды кэштен 0.01 секундта алып, `user2` таңдаған жаңа дизайнмен 1 секунд ішінде жинап береді!

5. **Таза Минималистік UI/UX және PPTX / PDF Қос Экспорты**:
   - Ешқандай артық көлеңкесіз (flat design), жинақы бұрыштармен және таза типографикамен жасалған 30 дизайн стилі.
   - Қосымша `reportlab` орнатуды қажет етпейтін ішкі **Pillow HD PDF** және **LibreOffice** қозғалтқышы.

6. **Толыққанды Әкімші панелі (`/admin`)**:
   - Пайдаланушылар, презентациялар және кэштен жылдам берілген сұраныстар статистикасы, сондай-ақ барлық қолданушыларға хабарлама тарату (Broadcast).

---

## 🚀 Іске қосу

1. Тәуелділіктерді орнату:
   ```bash
   pip install -r requirements.txt
   ```
2. `.env` файлын баптау (`TELEGRAM_BOT_TOKEN`, `ADMIN_IDS`, `DEEPSEEK_API_KEY` / `GEMINI_API_KEY`):
   ```bash
   cp .env.example .env
   ```
3. Ботты іске қосу:
   ```bash
   python bot.py
   ```
4. Жүйелік тестілерді тексеру:
   ```bash
   python tests/test_system.py
   ```
