# 🤖 AI Presentation Telegram Bot (Commercial Edition — Python)

Жасанды интеллект арқылы кәсіби деңгейдегі презентацияларды (**.PPTX** және **.PDF**) және қорғау мәтінін (**.DOCX**) автоматты түрде дайындайтын, толық монетизация (Kaspi Pay + Чек тексеру) және екі деңгейлі рефералдық-серіктестік жүйесі бар **Telegram-ға арналған Python жобасы**.

---

## 🌟 Барлық мүмкіндіктер тізімі

### 1. 💳 Монетизация, Тарифтер және Kaspi Чек Тексеру (`app/core/verifier.py`)
* **🎁 Тегін бастапқы бонус**: Әр жаңа қолданушыға тіркелген сәтте **1 тегін презентация** беріледі.
* **📦 Тарифтік пакеттер**:
  - **«Бір реттік» — 200 ₸** (`1 презентация + PDF + Қорғау сөзі`)
  - **«Студент (Хит)» — 2 000 ₸** (`15 презентация + барлық функциялар`)
  - **«Студент (VIP)» — 5 000 ₸** (`40 презентация + барлық функциялар`)
* **🧾 Kaspi Pay + Автоматты Чек Тексеру (`verifier.py`)**:
  - Қолданушы Kaspi арқылы төлеп, **PDF чекті** чатқа жібереді.
  - `verifier.py` чектің SHA-256 хэші мен транзакция нөмірін тексеріп (екінші рет қолданудан қорғау — **Anti-Fraud**), сомасын (`200`, `2 000`, `5 000 ₸`) және Kaspi деректерін автоматты түрде тексереді де, балансты сол мезетте толтырады (немесе скриншот болса, админге `✅ Растау` / `❌ Қабылдамау` батырмасымен жібереді).

### 2. 👥 Екі деңгейлі Рефералдық және Студенттік Серіктестік жүйе
* **1-деңгей (Тегін презентация)**: «Досыңды шақыр: 2 досың ботқа кірсе, автоматты түрде **+1 тегін презентация** беріледі».
* **2-деңгей (Ақша табу — 20% Серіктестік бонус)**: Егер студент ботқа **20 адамнан көп** шақырса және сол шақырылған адамдар жалпы **10 000 ₸** сомасына пакеттер сатып алса, студенттің серіктестік балансына автоматты түрде **+2 000 ₸ таза табыс** түседі (оны `💸 Табысты Kaspi-ге шығару` батырмасы арқылы шығарып алады).

### 3. 📊 Әкімші панелі (`/admin`) және `/give` командасы
* **Табыс статистикасы**: Бүгін қанша теңге түсті, жалпы қанша теңге түсті, қай пакеттен қанша сатылды (`200 ₸`, `2 000 ₸`, `5 000 ₸`) және серіктестерге қанша бонус есептелді.
* **Қолмен баланс немесе VIP беру (`/give`)**:
  - `/give 1234567 5` — ID бойынша 5 тегін презентация беру.
  - `/give 1234567 hit` — 15 презентация беру.
  - `/give 1234567 vip` — 40 презентация (VIP) беру.

### 4. 📄 Құжаттан Слайд жасау, Қорғау сөзі, Менің жобаларым және Глобалды Кэш
* **PDF / DOCX / TXT → Слайд**: Дайын реферат немесе мақала файлын жіберіп, слайд алу.
* **🎤 Қорғау сөзі (Шпаргалка)**: Әр слайдты қорғағанда айтатын дайын сөйлеу мәтінін `.DOCX` форматында жүктеп алу.
* **📂 Менің жобаларым**: Бұрын жасалған барлық жобаларды кез келген уақытта қайта тартып алу.
* **⚡ Ақылды Глобалды Кэш**: Егер `user1` жасаған тақырып пен бет санын кейін `user2` сұраса (тіпті дизайны басқа болса да), бот оны қайта генерацияламай, 1 секундта жаңа дизайнмен береді.

## 🚀 Іске қосу

1. `.env` файлында өз деректеріңізді көрсетіңіз:
   ```env
   TELEGRAM_BOT_TOKEN=сіздің_токеніңіз
   ADMIN_IDS=сіздің_telegram_id
   KASPI_PAY_URL=https://pay.kaspi.kz/pay/YOUR_KASPI_LINK
   DEEPSEEK_API_KEY=сіздің_deepseek_кілтіңіз
   ```
2. Ботты іске қосу:
   ```bash
   python bot.py
   ```
3. Жүйелік тестілерді тексеру:
   ```bash
   python tests/test_system.py
   ```
