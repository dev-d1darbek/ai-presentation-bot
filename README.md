# AI арқылы автоматты презентация жасайтын Telegram бот

Бұл жоба пайыздық деңгейде өндіріске дайын, толық жұмыс істейтін Telegram бот. Бот пайдаланушымен сұхбат құрып (FSM арқылы), тақырып, слайд саны, сурет қажеттілігі, тіл және дизайн стилін анықтап, OpenAI (LLM) көмегімен мазмұн жасап, Pexels/OpenAI Image API арқылы суреттер таңдап, python-pptx арқылы кәсіби PPTX презентация файлын және әр слайдтың қысқаша жоспары мен қорғау мәтінін дайындайды.

## Технологиялық стек:
- Python 3.12+
- aiogram 3
- OpenAI API (GPT-4o & DALL-E 3)
- Pexels API
- python-pptx
- Docker & Docker Compose
